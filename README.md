# The Webspaces Kit

**https://webspaces.space/kit/**

Free (CC0) Smooth Voxel models in the Webspaces house style. Put one in any world with a single tag:

```html
<model src="https://webspaces.space/kit/models/pine.svox"
  style="transform: translate3d(0cm, 255cm, -300cm) scale3d(1.6, 1.6, 1.6)"></model>
```

Every model is a few lines of plain text in [`models/`](models/), generated by [`make.py`](make.py). Change a
color or a shape and re-run `python make.py`, or edit a `.svox` file by hand. `catalog.py` rebuilds the catalog page.

Facts worth knowing when placing SVOX models in a webspace:

- Every voxel is 12.5 cm; the file's `scale` is ignored. Resize with `scale3d` in the transform.
- Models are centered on their transform. To stand a model on `flat` ground (y = 75 cm), set its y to
  `75 + height / 2`.
- Thin parts (trunks, stems, legs) should be at least 2 voxels thick and use a material with `deform = 1`, or
  smoothing melts them away.

Contributions welcome. Keep the style: few voxels, soft deform, flat friendly colors.
